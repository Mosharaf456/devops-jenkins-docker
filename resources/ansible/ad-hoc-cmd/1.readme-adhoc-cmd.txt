The errors you're encountering stem from SSH's strict host key verification and potential changes to the SSH host key fingerprints of the target servers. Let's address the issues step-by-step:

1. Host Key Changed
The error shows that the host key for some servers (e.g., 192.168.1.101) has changed. This usually happens when:

The server has been reinstalled.
The SSH key on the server was regenerated.
You're connecting to a different server at the same IP address.
Solution: You need to remove the old key from the ~/.ssh/known_hosts file.

Run the following commands:
ssh-keygen -f "/home/btl-671/.ssh/known_hosts" -R "192.168.1.101"
ssh-keygen -f "/home/btl-671/.ssh/known_hosts" -R "192.168.1.102"


This removes the old host keys for the respective IPs.
